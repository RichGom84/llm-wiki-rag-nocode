# 강사 운영 안내

## 수업 범위

2~3시간, 코딩 비경험자를 위한 VS Code + OpenAI Codex 실습입니다. 수강생은 자연어로 작업을 요청하고 파일 결과를 확인합니다. 환경 설치와 계정 확인은 수업 전에 끝내는 것을 권장합니다. 설치를 수업에 포함하면 180분 편성을 사용하세요.

| 활동 | 120분 | 150분 | 180분 |
|---|---:|---:|---:|
| 개념과 결과물 | 15 | 15 | 20 |
| VS Code와 Codex 준비 | 15 | 25 | 35 |
| RAG 검색과 답변 | 25 | 25 | 30 |
| Wiki 작성과 질문 | 25 | 30 | 35 |
| 휴식 | 0 | 10 | 10 |
| 비교와 변경 반영 | 25 | 25 | 30 |
| 저장과 공유 | 15 | 20 | 20 |

## 리허설

- 대표 Windows/macOS 환경에서 Python 실행 명령과 Codex 로그인을 확인합니다.
- 새 ZIP으로 열어 지시문 01~10을 실행합니다. 확장 UI와 실모델의 파일 작성은 수업 전 직접 검증해야 합니다.
- RAG 검색은 준비된 BM25 구현을 사용합니다. "RAG를 알아서 구현해줘"라고 요청하면 학생별 구현이 달라지므로 비교 수업에서는 사용하지 않습니다.
- Wiki 등록 검사는 출처 ID와 링크, 원문 변경 상태만 검사합니다. 내용의 사실성은 원문 대조가 필요합니다.
- 답변 채팅을 새로 만들고, 읽은 파일 기록을 확인합니다. 정답표나 다른 답변을 읽은 결과는 비교에서 제외합니다. 이는 완전한 기술적 격리가 아닙니다.
- 모델과 계정의 사용 한도에 따라 진행 시간이 달라집니다. 실패한 학생에게 다른 계정으로 제한을 우회하도록 안내하지 않습니다.
- Python 도구는 OpenAI API를 직접 호출하지 않습니다. ChatGPT 로그인 방식에서는 Codex의 계정 사용 한도가 적용됩니다. 토큰 비용과 속도의 정량 비교는 이 수업 범위에 넣지 않습니다.

## 평가

기존 `teacher/ANSWER_KEY.md`와 같은 가상 원문과 질문을 사용합니다. 답변을 다 만든 후 정답표로 평가합니다. 정확성과 근거를 각각 0~2점으로 평가하고, 변경 전후의 질문 7~9를 확인합니다. 질문 10은 확인 불가가 기대 답변입니다.

## 장애 대처 10가지

1. 폴더가 다름: README.md, materials, src, vscode가 함께 있는 최상위 폴더를 엽니다.
2. Python 실행 불가: Python 실행기를 설치하고 VS Code를 다시 시작합니다.
3. Codex 아이콘 없음: 공식 확장 설치와 사이드바 명령을 확인합니다.
4. 로그인/이용 불가: 계정과 조직의 사용 허용 여부를 확인합니다.
5. 실행 승인 요청: 명령과 대상 경로를 읽고 수업 작업인지 확인합니다. 제한 자체를 해제하도록 안내하지 않습니다.
6. 근거 파일 없음: prepare, rag-index, rag-context의 순서와 출력 경로를 확인합니다.
7. Wiki 등록 오류: 오류에 나온 페이지의 출처와 원문 링크를 보완합니다.
8. D11 이후 질문 오류: RAG 색인과 Wiki 페이지를 각각 갱신합니다.
9. 답변이 정답표를 읽음: 새 채팅에서 지정 근거 파일만 사용해 재실행합니다.
10. ZIP에 답변이 없음: 답변을 output/answers에 저장했는지 확인합니다.
