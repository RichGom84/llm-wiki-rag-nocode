# 수업 프롬프트

실제 실행 지시문은 `src/workshop.py`의 `ANSWER_RULES`와 `build_wiki`에 들어 있습니다. 노트북에 내장되어 수강생이 복사하거나 수정할 필요가 없습니다.

답변 원칙: 제공된 근거로만 답하고 원문 ID를 인용합니다. 근거가 부족하면 확인할 수 없다고 알립니다. 변경 공지의 적용일과 대체 범위를 확인합니다.

Wiki 생성 원칙: 여러 원문을 주제별로 종합하되 조건과 예외를 유지하고, 출처를 남깁니다. 관련 페이지 링크와 원문 파일 링크는 프로그램이 고정된 경로로 추가합니다.

변경 원칙: 원본은 보존하고 영향을 받는 주제 페이지를 다시 생성합니다. 기존 페이지는 버전 폴더에 보관하고 변경 이유를 기록합니다.
